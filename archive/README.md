# Archive

Historical artifacts from the project's first iteration (March 2026). Kept for provenance —
**do not install from here**; the current skills live in [`../skills/`](../skills/).

- `advisor-*.skill` — v0 exports (ZIP archives, one `SKILL.md` each). These predate the
  dispatcher, the output constraints (600-word cap, quantification requirement), and the
  language-adaptive output rule.
- `conversation-summary.md` — the original design log (in Chinese): how the 17-advisor
  board was assembled in three batches, which advisors were considered and rejected
  (e.g., Porter's Five Forces in favor of Helmer's 7 Powers), and the cross-advisor
  boundary-drawing that followed.
